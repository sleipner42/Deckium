# Code of Conduct

Deckium follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, constructive, and considerate. Harassment, discrimination, and
abusive behavior are not tolerated in project spaces.

Report conduct concerns to support@deckium.xyz. Reports will be reviewed
promptly and handled as confidentially as practical.
